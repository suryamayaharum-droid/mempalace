# Harumverso namespace for MemPalace

Harumverso is an Arte Harum / Harum Noir knowledge project. The canonical blueprint lives in:

- `suryamayaharum-droid/SARASWATI-HIVE-MIND/docs/HARUMVERSO_BLUEPRINT.md`
- public facade: `suryamayaharum-droid/astro-blog-starter-template`

## Suggested Palace structure

```
wing: harumverso
  hall: creators
  hall: references
  hall: classics
  hall: outliers
  hall: techniques
  hall: noir
  hall: editorial
  hall: products
```

### Store
- source URLs and dates;
- research notes;
- why a reference matters;
- relationships between artists/principles;
- editorial decisions;
- tested Harum Noir exercises;
- publication receipts.

### Do not store as authoritative fact
- guessed metrics;
- unverified social handles;
- copied copyrighted works;
- passwords, tokens, cookies or private keys.

The public site should consume curated outputs, not raw memory dumps.
